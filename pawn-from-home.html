The problem

Where it started

  1. 01

    Paperwork before any value

    The flow asked for an account with many fields before showing anything.

  2. 02

    One service, one category

    At-home pawn led to an electronics-only flow, so gold, the core of the business, had no path.

  3. 03

    Failures nobody could see

    A hidden step, rejected PDFs and a broken mobile flow, all without an explanation.

Key decisions

Three calls that shaped it

01

Show the estimate before the account

The group’s strongest flow shows an offer first and asks for login at the end. People who have seen a number are invested enough to finish.

Details
Rejected
Account first, with a long registration before any value.
Trade-off
More anonymous drafts, so people return to their step after login.
02

One page, five categories

Gold needs karat and weight, electronics need model and condition. One page with a category selector and dynamic questions replaced an electronics-only redirect.

Details
Rejected
A separate page per category, duplicating the flow five times.
Trade-off
Diamonds, watches and bags still need fields defined with the client.
03

Design the unhappy paths

Invalid IBAN, invalid ID number, expired offers and disqualified devices are where trust breaks. Each got its own designed state instead of a generic error.

Details
Rejected
One generic error page for every failure.
Trade-off
More screens to maintain, grouped in their own section.

Outcome

What the team got

  • 931 Interactive targets audited against WCAG before handoff
  • 3 Widths wireframed for every step
  • 1→4 Sign-in moved from the first step to the fourth
